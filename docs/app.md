# About this App

A simple hello world webservice container. 

# Install Dependencies

To install the dependencies for this application you can run the following.
```
    python3 -m pip install -r requirements.txt
```

# Run Tests

To run the tests, just run `pytest`.

# Running Application Locally

To run the application locally, you can use the `start.sh` script. Not that by default this binds to `0.0.0.0`, so on your local machine you may wish to change that to `localhost`.
